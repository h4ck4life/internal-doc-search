📋 API Endpoints (13)
GET /search?q=&limit=&label= Two-stage semantic search; multi-label (OR) with -prefix exclusion
GET /labels List distinct labels (with URL counts) for chip-based search
GET /health Service readiness — Qdrant connectivity check
POST /ingest Start background re-crawl (409 if already running)
GET /ingest/status Current crawl progress (running/total/chunks)
GET /docs-summary URL count, chunk count, last crawl timestamp
GET /urls List all configured crawl URLs with status
POST /urls Add new crawl URL (deep_crawl, deep_crawl_max_depth)
PUT /urls/{id} Update URL string, label, or deep crawl settings
DEL /urls/{id} Remove crawl URL
GET /config Get all configuration values
PUT /config Update configuration (label_match_mode: hard|boost, weight 0–1)
MCP /mcp LLM tools: list_labels, search_docs(labels=[]), add_url_to_crawl, trigger_crawl
🤖 MCP Setup — Connect LLM Agents

Add this endpoint to your LLM client to enable semantic doc search from any agent. Four tools: list_labels (call first to discover topics), search_docs, add_url_to_crawl, trigger_crawl.

Claude Code

Option A — Add globally (all projects):

claude mcp add --scope user --transport http doc-search http://localhost:8000/mcp/

Option B — Add to this project only:

claude mcp add --transport http doc-search http://localhost:8000/mcp/

Option C — Project .mcp.json (auto-connects when Claude Code opens this repo):

{
  "mcpServers": {
    "doc-search": {
      "type": "http",
      "url": "http://localhost:8000/mcp/"
    }
  }
}

Claude Desktop

Settings → Developer → MCP Servers → Add:

{
  "doc-search": {
    "type": "http",
    "url": "http://localhost:8000/mcp/"
  }
}

Codex / Custom Client
