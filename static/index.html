▸⚙️ Configuration
500–5000 charsMax characters per chunk. Larger keeps more context per result, smaller gives tighter matches. Re-ingest after changing.
0–500 charsCharacters shared between neighbouring chunks. Raise if answers get cut off at chunk boundaries. Re-ingest after changing.
1–20 resultsHow many results to return per search. Higher shows more (and more pages), lower keeps just the top hits.
10–200 candidatesCandidates fetched before the cross-encoder reranks them. Higher is more accurate but slower, lower is faster.
hard=filter · boost=score-blendhard hides off-label docs, boost lets them surface lower down. Use boost when your labels may be incomplete.
0–1 (label blend)Boost mode only. How strongly a label match lifts a result. Higher favours on-label hits.
0–1 (filter low CE)Hides results below this cross-encoder score. Raise to filter out weak matches, 0 shows everything.

PUT/urls/{id}Update URL string, label, or deep crawl settings
DEL/urls/{id}Remove crawl URL
POST/urls/{id}/recrawlRe-crawl a single URL in background
GET/configGet all configuration values

▸🤖 MCP Setup — Connect LLM Agents

Add this endpoint to your LLM client to enable semantic doc search from any agent. Four tools: list_labels (call first to discover topics), search_docs, add_url_to_crawl, trigger_crawl, recrawl_url (single-URL refresh).

Claude Code

Option A — Add globally (all projects):

claude mcp add --scope user --transport http doc-search http://localhost:8000/mcp/

Option B — Add to this project only:

claude mcp add --transport http doc-search http://localhost:8000/mcp/

Option C — Project .mcp.json (auto-connects when Claude Code opens this repo):

{
  "mcpServers": {
    "doc-search": {
      "type": "http",
      "url": "http://localhost:8000/mcp/"
    }
  }
}

Claude Desktop

Settings → Developer → MCP Servers → Add:

{
  "doc-search": {
    "type": "http",
    "url": "http://localhost:8000/mcp/"
