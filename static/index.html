🤖 MCP Setup — Connect LLM Agents

Add this endpoint to your LLM client to enable semantic doc search from any agent. Three tools available: search_docs, add_url_to_crawl, trigger_crawl.

Claude Code

Create .mcp.json in your project root or add to ~/.claude/claude_desktop_config.json:

{
  "mcpServers": {
    "doc-search": {
      "type": "url",
      "url": "http://localhost:8000/mcp"
    }
  }
}

Claude Desktop

Settings → Developer → MCP Servers → Add:

{
  "doc-search": {
    "type": "url",
    "url": "http://localhost:8000/mcp"
  }
}

Codex / Custom Client

Any MCP-compatible client. Endpoint URL:

http://localhost:8000/mcp
